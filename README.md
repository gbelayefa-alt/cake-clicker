# Cake Clicker Game

An incremental browser-based game developed as a pair programming project using JavaScript, HTML, and CSS.  
Players click on the cake to earn points and progress through the game while interacting with dynamic UI elements and upgrades.  
The project focused on implementing game-state management, event-driven programming, and interactive web design concepts.  
This project strengthened my experience collaborating on software development and building engaging browser applications.

## Technologies Used
- JavaScript
- HTML
- CSS

## Features
- Interactive click-based gameplay
- Dynamic score and progress tracking
- Event-driven user interactions
- Responsive user interface updates
- Incremental gameplay mechanics

## How to Run
